Privacy Policy

Last updated: 14 October 2026

Thinkfork runs on your Mac. We operate no servers for it, and we do not collect, receive or store your conversations, files, API keys or usage data.

What stays on your computer

  • Your canvases, settings and provider configuration, in ~/Library/Application Support/Thinkfork.
  • Your API key, in a file in that folder that only your user account can read.
  • Session records created by the assistant engine, in ~/.dsh.

Deleting these folders removes the data. Nothing is synced anywhere.

What is sent, and to whom

  • Your chosen model provider. Your messages, the parts of your files and command results the assistant needs, and your API key are sent directly from your Mac to the provider you configure (for example DeepSeek, OpenRouter, OpenAI, Anthropic, Google, or an endpoint you enter). We are not a party to that exchange. The provider’s own privacy policy and terms apply to it.
  • Model lists. When you ask the app to fetch a provider’s model list, it contacts that provider.
  • Things you ask the assistant to do. If you ask it to browse the web, run commands, or connect to a service, those actions use the network as you directed.

Telemetry

The assistant engine that Thinkfork runs includes optional telemetry. Thinkfork turns it off. The app has no analytics, advertising, tracking or crash-reporting of its own.

This website

The site is a static page hosted on GitHub Pages. It sets no cookies and has no analytics. Your browser remembers your language choice locally. The download button asks GitHub’s public API for the latest release, and downloads are served by GitHub, which receives your IP address under GitHub’s privacy statement.

Children

Thinkfork is not directed at children under 13.

Changes and contact

If this policy changes, the new version will be posted here with a new date. Questions: open an issue at github.com/pipiandxixi/dsh-canvas-releases.

隐私政策

最近更新:2026 年 10 月 14 日

Thinkfork 运行在你的 Mac 上。我们没有为它运行任何服务器,也不会收集、接收或保存你的对话、文件、API key 和使用数据。

保存在你电脑上的内容

  • 画布、设置和提供方配置,位于 ~/Library/Application Support/Thinkfork。
  • 你的 API key,保存在该文件夹里的一个文件中,只有你的用户账户可以读取。
  • 助手引擎产生的会话记录,位于 ~/.dsh。

删除这些文件夹就会清除数据。没有任何内容会被同步到别处。

会发送什么、发送给谁

  • 你选择的模型提供方。你的消息、助手需要用到的文件片段和命令结果,以及你的 API key,会直接从你的 Mac 发送给你配置的提供方(例如 DeepSeek、OpenRouter、OpenAI、Anthropic、Google,或你填写的接口)。我们不参与这一过程,适用的是该提供方自己的隐私政策和条款。
  • 模型列表。当你让应用获取某个提供方的模型列表时,它会连接该提供方。
  • 你要求助手做的事。如果你让它浏览网页、运行命令或连接某个服务,这些操作会按你的指示使用网络。

遥测

Thinkfork 所运行的助手引擎自带可选的遥测功能,Thinkfork 已将其关闭。应用本身没有统计分析、广告、跟踪或崩溃上报。

本网站

本站是托管在 GitHub Pages 上的静态页面,不设置 Cookie,也没有统计分析。浏览器会在本地记住你选择的语言。下载按钮会向 GitHub 的公开接口查询最新版本,下载文件由 GitHub 提供,GitHub 会按其隐私声明获取你的 IP 地址。

未成年人

Thinkfork 不面向 13 岁以下的儿童。

变更与联系

本政策如有变更,新版本会连同新的日期发布在此页。如有疑问,请到 github.com/pipiandxixi/dsh-canvas-releases 提交 issue。
