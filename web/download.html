Download Thinkfork

Free. For Apple silicon Macs (M1 or later) running macOS 13.5 or later. Intel Macs and Windows are not supported yet.

Download for Mac (Apple silicon)

First, check your Mac

  1. Click the Apple menu in the top-left corner, then choose About This Mac.
  2. Look at Chip. If it says Apple M1, M2, M3, M4 or later, this download is for you.
  3. If it says Processor: Intel, this version will not open on your Mac.
  4. Also check the macOS version: it must be 13.5 (Ventura) or later.

Install

  1. Open the downloaded .dmg and drag Thinkfork into Applications.
  2. Open it from Applications. macOS will say the app was downloaded from the internet and ask you to confirm; choose Open.
  3. That’s the only prompt. Thinkfork is signed with an Apple Developer ID and notarized by Apple.
  4. On first launch, open Settings and add the API key of the model provider you want to use. Thinkfork needs no account of its own.

Updates

Thinkfork tells you when a newer version is available (you can turn this off in Settings > About). Updates are manual for now: download the latest version here and replace the app in Applications. Your canvases and settings are kept.

Other platforms

Thinkfork is built for Apple silicon only for now. Intel Macs and Windows are not available.

下载 Thinkfork

免费。适用于 Apple 芯片的 Mac(M1 及更新),系统 macOS 13.5 或更高。暂不支持 Intel Mac 和 Windows。

下载 Mac 版(Apple 芯片)

先确认你的 Mac

  1. 点屏幕左上角的苹果菜单,选择“关于本机”。
  2. 看“芯片”一栏。如果写着 Apple M1、M2、M3、M4 或更新的型号,就可以用这个安装包。
  3. 如果写的是“处理器:Intel”,这个版本在你的 Mac 上打不开。
  4. 同时确认 macOS 版本:需要 13.5(Ventura)或更高。

安装

  1. 打开下载的 .dmg,把 Thinkfork 拖进“应用程序”。
  2. 从“应用程序”里打开。macOS 会提示这是从互联网下载的应用,请你确认,点“打开”即可。
  3. 只会有这一次提示。Thinkfork 已用 Apple 开发者 ID 签名,并通过 Apple 公证。
  4. 第一次启动后,打开“设置”,填入你要使用的模型提供方的 API key。Thinkfork 本身不需要账号。

更新

有新版本时 Thinkfork 会提示你(可在“设置 > 关于”里关闭)。目前更新需要手动完成:回到这里下载最新版本,替换“应用程序”里的旧版本即可,你的画布和设置都会保留。

其他平台

目前 Thinkfork 只提供 Apple 芯片版本,暂无 Intel Mac 和 Windows 版。

另见版本说明、隐私政策和使用条款。
