DSH Canvas

Explore AI conversations as a tree on an infinite canvas. Branch from any reply, and keep everything on your own computer.

Download for macOS

Apple silicon Macs, macOS 13.5 or later.

What it does

  • See the whole conversationEvery question and reply is a card on a canvas, connected as a tree, so you can see how an idea developed.
  • Ask from anywherePick any reply and keep going. Asking again from an earlier point branches the conversation instead of overwriting it.
  • Bring your own modelUse DeepSeek, OpenRouter, OpenAI, Anthropic, Google Gemini, or any OpenAI-compatible endpoint with your own key.
  • Local firstCanvases, settings and your API key stay on your computer. Work in any folder you choose.

Installing

Open the downloaded file and drag DSH Canvas into Applications

While the app is not yet signed with an Apple Developer ID, macOS may block the first launch. Right-click the app and choose Open, then confirm. If it still refuses, run xattr -cr "/Applications/DSH Canvas.app" in Terminal and open it again.
