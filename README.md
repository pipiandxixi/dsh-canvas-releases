# Thinkfork website

Product site (`web/`, published to https://thinkfork.cc with GitHub Pages) for **Thinkfork**, a Mac app that lets you explore AI conversations as a tree on an infinite canvas.

- **Get the app:** the [Mac App Store](https://apps.apple.com/app/id6836753524). Requires an Apple silicon Mac with macOS 15 or later.
- Downloads of earlier builds are no longer offered from this repository or the website.

Thinkfork is built on the open-source DeepSeek Harness (DSH) and is not affiliated with, endorsed by, or sponsored by DeepSeek. Third-party open-source licenses are included in the app and in `web/notices.txt`.
